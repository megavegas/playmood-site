Independent by design

  1. PlayMood does not follow Google Play or any restricting store policy.
  2. It is fully independent — made only for free, ad-free listening.
  3. Enjoy it to the fullest.

Party vs TV sync

  1. Party: two or more phones on one Wi‑Fi — no TV required.
  2. Host starts Party on Home; guests join with the same 4-digit PIN.
  3. TV sync: separate Home card; PIN shown on PlayMood TV.
  4. If the router uses AP isolation, phones cannot discover each other.

Sideload install

  1. Allow install from unknown sources for your browser/file manager.
  2. Download and install the APK.
  3. Grant audio permission (READ_MEDIA_AUDIO).
  4. Later updates arrive inside the app or from this page.

استقلال PlayMood

  1. این اپ از سیاست‌های Google Play یا هیچ ارگان محدودکننده‌ای پیروی نمی‌کند.
  2. کاملاً مستقل است؛ هدف فقط لذت داشتن یک اپ رایگان برای شنیدن بهترین موسیقی بدون تبلیغ است.
  3. پس از استفاده از این اپ نهایت لذت را ببرید.

مهمانی (Party) در برابر همگام TV

  1. مهمانی: دو یا چند گوشی روی یک Wi‑Fi — نیازی به تلویزیون نیست.
  2. میزبان روی Home → Party → Start party؛ مهمان همان PIN چهاررقمی را Join می‌کند.
  3. TV sync: کارت جدا روی Home است؛ PIN روی صفحهٔ تلویزیون با اپ PlayMood TV.
  4. اگر روتر «AP isolation» دارد، گوشی‌ها همدیگر را پیدا نمی‌کنند.

نصب sideload

  1. از تنظیمات اندروید، نصب از منابع ناشناس را برای مرورگر/فایل‌منیجر مجاز کنید.
  2. APK را دانلود و نصب کنید.
  3. دسترسی صوت (READ_MEDIA_AUDIO) را بدهید.
  4. بروزرسانی‌های بعدی از داخل اپ یا همین صفحه می‌آید.
